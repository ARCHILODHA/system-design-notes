# Heartbeat Mechanism

## Definition

Heartbeat is a periodic signal sent to indicate a service is alive.

---

## Uses

- Health checks
- Cluster monitoring
- Leader election
- Failure detection

---

## Example

Server sends heartbeat every 5 seconds.

If heartbeat stops, the node is marked unhealthy.

---

## Advantages

- Detect failures quickly
- Improve availability

---

## Interview Question

Why are heartbeats important?

They help identify failed servers automatically.
