# gRPC vs REST

## REST
- HTTP based
- JSON payloads
- Human-readable

## gRPC
- HTTP/2 based
- Protocol Buffers
- Faster and compact

## Comparison

| Feature | REST | gRPC |
|----------|------|------|
| Format | JSON | Protobuf |
| Speed | Moderate | High |
| Streaming | Limited | Native |
| Browser Support | Excellent | Limited |

## Use Cases
- REST: Public APIs
- gRPC: Microservices
