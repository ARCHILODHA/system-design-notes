# Cache Hit vs Cache Miss

## Cache Hit

Requested data is found in cache.

Result:
- Fast response
- No database query

---

## Cache Miss

Requested data is not found in cache.

Result:
- Database is queried
- Data is stored in cache

---

## Hit Ratio

```
Hit Ratio = Cache Hits / Total Requests
```

Higher hit ratio means better cache performance.

---

## Goal

Maximize cache hits and minimize misses.
