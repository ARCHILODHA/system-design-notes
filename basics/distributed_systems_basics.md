# Distributed Systems Basics

## Definition

A distributed system consists of multiple computers working together as one system.

## Characteristics

- Scalability
- Fault Tolerance
- Reliability
- Availability

## Challenges

- Network Failures
- Data Consistency
- Latency
- Synchronization

## Examples

- Google Search
- Netflix
- Amazon
- Facebook

## Goals

- Handle Millions of Users
- Remain Available During Failures
- Scale Efficiently
