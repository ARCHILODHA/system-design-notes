# Caching

## What is Caching?

Caching stores frequently accessed data in fast storage to reduce latency.

## Advantages

- Faster Response Time
- Reduced Database Load
- Better User Experience

## Types

- Client Cache
- CDN Cache
- Server Cache
- Database Cache

## Cache Eviction Policies

- LRU
- LFU
- FIFO

## Popular Technologies

- Redis
- Memcached
