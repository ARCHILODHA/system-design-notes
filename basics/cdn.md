# Content Delivery Network (CDN)

## Definition

A CDN is a network of geographically distributed servers used to deliver content quickly.

## Benefits

- Reduced Latency
- Faster Content Delivery
- Reduced Origin Server Load

## Example

User (India)
     |
Nearby CDN Server
     |
Origin Server

## Popular CDNs

- Cloudflare
- Akamai
- AWS CloudFront
