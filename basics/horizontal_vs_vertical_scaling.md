# Horizontal vs Vertical Scaling

Scaling improves system performance.

---

# Vertical Scaling

Increase power of existing server.

Example:
- More RAM
- Faster CPU

## Advantages

- Simple
- Easy management

## Disadvantages

- Hardware limit
- Expensive

---

# Horizontal Scaling

Add more servers.

Example:
- Multiple application servers

## Advantages

- Better fault tolerance
- Unlimited scaling

## Disadvantages

- Complex architecture

---

# Comparison

| Vertical | Horizontal |
|---|---|
| Scale up | Scale out |
| One server | Multiple servers |
| Limited | Highly scalable |

---

# Real Examples

Vertical:
- Small startups

Horizontal:
- Google
- Amazon
- Netflix
