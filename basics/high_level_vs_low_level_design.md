# High Level Design vs Low Level Design

Both are important in software architecture.

---

# High Level Design (HLD)

Describes overall system architecture.

## Focus

- Components
- Services
- Databases
- Communication

## Example

Designing YouTube architecture.

---

# Low Level Design (LLD)

Describes internal implementation details.

## Focus

- Classes
- Methods
- APIs
- Data structures

## Example

Designing video upload class structure.

---

# Comparison

| HLD | LLD |
|---|---|
| Big picture | Internal details |
| Architecture | Implementation |
| Scalability | Code structure |

---

# Importance

HLD:
- System planning

LLD:
- Clean implementation

Both together create scalable systems.
