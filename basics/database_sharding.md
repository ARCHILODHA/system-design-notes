# Database Sharding

## What is Sharding?

Sharding divides a large database into smaller databases called shards.

## Why Use It?

- Better Scalability
- Reduced Load
- Faster Queries

## Example

Users 1-100000  -> Shard A
Users 100001-200000 -> Shard B

## Challenges

- Rebalancing
- Cross-Shard Queries
- Data Consistency
