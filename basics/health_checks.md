# Health Checks

## Definition

Health checks verify whether a server or service is working properly.

---

## Types

### Liveness Check

Determines if application is alive.

### Readiness Check

Determines if application is ready to receive traffic.

---

## Benefits

- Removes unhealthy servers
- Improves availability
- Prevents downtime

---

## Examples

- Kubernetes Probes
- AWS Load Balancer Health Checks
