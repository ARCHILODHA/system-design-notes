# System Design Checklist

Use this checklist during interviews or architecture planning.

---

# 1. Requirements Gathering

- Functional requirements
- Non-functional requirements
- Scale estimation

---

# 2. Capacity Estimation

- Users
- Requests/sec
- Storage needs
- Bandwidth

---

# 3. High Level Design

- Clients
- API Gateway
- Services
- Databases

---

# 4. Database Design

- SQL or NoSQL
- Sharding
- Replication

---

# 5. Scalability

- Load balancer
- Auto scaling
- CDN

---

# 6. Reliability

- Failover
- Redundancy
- Monitoring

---

# 7. Security

- Authentication
- Authorization
- Encryption

---

# 8. Optimization

- Caching
- Queues
- Compression

---

# 9. Monitoring

- Logs
- Metrics
- Alerts

---

# 10. Tradeoffs

Always explain:
- Pros
- Cons
- Design decisions
